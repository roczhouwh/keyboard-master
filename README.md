# 键盘小达人 - 趣味打字游戏

## 🎮 项目简介

键盘小达人是一款专为小学生设计的趣味打字游戏，通过游戏化的方式帮助孩子们熟悉键盘键位，提高打字速度和准确性。支持多年级词库切换，适合不同年龄段的学生使用。

## ✨ 功能特点

### 🎯 游戏模式

| 模式 | 目标字符 | 难度是否生效 | 说明 |
|------|---------|-------------|------|
| **字母模式** | A-Z a-z | ❌ 固定60秒 | 练习单个字母按键，大小写随机 |
| **字符模式** | A-Z a-z 0-9 , . / | ❌ 固定60秒 | 练习字母、数字和标点符号 |
| **单词模式** | 年级词库随机单词 | ✅ 词库范围 | 固定60秒；从当前词库按难度 tier 取词，2×得分 |
| **学单词模式** | 年级词库记背单词 | ❌ 无倒计时 | 看词+默写两阶段，错词复习，进度持久化 |
| **限时速打** | A-Z a-z 限时输入 | ✅ 超时时间 | 简单3秒 / 中等2秒 / 困难1秒，超时自动算错 |

### 📚 多年级词库
- **三年级 ~ 六年级** 四套独立词库，每套按 easy/medium/hard 三级分层
- 每个单词附带中文释义，单词模式下在单词下方显示
- 开始前可自由切换，选中即加载
- 加载失败自动回退到内置词库

### 🏆 游戏特色
- **多难度级别**：简单、中等、困难三个难度等级（仅单词和限时速打生效）
- **难度置灰提示**：字母/字符模式下难度选择器自动禁用并显示提示
- **实时反馈**：正确/错误的视觉和听觉反馈
- **计分系统**：根据输入速度和准确性计分
- **连击奖励**：连续正确输入获得额外分数
- **音效系统**：支持背景音乐和按键音效
- **响应式设计**：适配不同屏幕尺寸

### 📊 统计功能
- **实时得分**：游戏过程中实时显示得分
- **正确率**：计算并显示输入正确率
- **最高连击**：记录游戏过程中的最高连击数
- **游戏结束统计**：显示最终得分、正确率和最高连击

## 🚀 安装和运行

### 方法1：直接打开文件（简单）
1. 下载或克隆项目到本地
2. 在浏览器中直接打开 `index.html` 文件
3. 开始游戏！

### 方法2：使用本地服务器（推荐，音频需要）
1. 下载或克隆项目到本地
2. 打开命令提示符，导航到项目目录
3. 运行以下命令启动本地服务器：
   ```bash
   # 使用 Python 3
   python -m http.server 8080

   # 或使用 Python 2
   python -m SimpleHTTPServer 8080
   ```
4. 在浏览器中访问 `http://localhost:8080`
5. 开始游戏！

## 🎵 添加音频文件

游戏支持音效功能，需要在 `sounds` 目录中添加以下音频文件：

1. **bg_music.mp3** - 背景音乐，建议使用轻松愉快的儿童音乐
2. **key_sound.mp3** - 按键音效，建议使用短促清脆的声音
3. **correct_sound.mp3** - 正确输入音效，建议使用积极向上的提示音
4. **wrong_sound.mp3** - 错误输入音效，建议使用温和的提示音
5. **levelup_sound.mp3** - 成就音效，建议使用庆祝性的短音乐

**注意**：如果没有添加音频文件，游戏会静默运行，但所有功能都正常。

## 🎮 游戏玩法

### 开始游戏
开始界面采用**分步向导**，每步只显示当前需要的选项：

1. **第 1 步 · 选模式**：选择字母、字符、单词、学单词或限时速打
2. **第 2 步 · 设置**：每种模式只显示它需要的选项
   - **字母 / 字符模式**：无需设置，直接开始
   - **单词模式**：选择难度（影响词长）和年级词库
   - **学单词模式**：选择年级词库和每批词数
   - **限时速打**：选择难度（决定超时时长）
3. 点击 "开始游戏" 按钮

### 游戏过程
1. **字母模式**：屏幕上会显示一个字母，按下键盘上对应的按键
2. **字符模式**：屏幕上会显示字母、数字或标点，按下对应按键
3. **单词模式**：屏幕上会显示一个单词及其中文释义，依次按下键盘上对应的按键
4. **学单词模式**：选年级（词库）和批次（默认10词，可调 10/20/30）；每词先「看词」照打一遍，再「默写」凭中文记忆打英文，默写/复习阶段有 **3 颗爱心**（每打错一键少一颗，爱心耗尽自动揭示拼写照打一遍）；遇到不会的词也可点「看答案」揭示拼写续打当前词（不跳过）。爱心耗尽/看答案的词判定未掌握：默写阶段进入复习队列，复习阶段保持未掌握、下次游戏重新抽取。每一词打完后先展示完成反馈再进入下一词。无倒计时压力，掌握进度跨会话保存。设置区可打开「**词库管理**」：查看整库单词学习状态、搜索/筛选、把已掌握的词放回未学习、把单词标记为**重点词**（重点词在批次里出现概率更高，约 ×3），并支持批量操作
5. **限时速打**：屏幕上会显示字母，需要在规定时间内按下对应的按键（简单3秒，中等2秒，困难1秒），超时未输入将视为错误

### 排行榜功能
- **常驻展开**：排行榜标题下方直接展示所有记录（学单词模式不参与排行榜）
- **实时同步**：选择不同的游戏模式和难度时，排行榜会自动显示对应的排行榜数据
- **当前设置显示**：排行榜上方会显示当前选择的游戏模式和难度
- **数据持久化**：游戏结束后，得分会自动保存到本地排行榜
- **导出/导入**：支持导出和导入排行榜数据，方便备份和分享

### 操作方法
- **真实键盘**：直接按下键盘上对应的按键
- **虚拟键盘**：点击屏幕上显示的虚拟键盘按键
- **音效控制**：点击 "🔊 音效" 按钮开启/关闭音效
- **音量调节**：点击 "🔉 音量+" 和 "🔈 音量-" 按钮调节音量

### 游戏结束
- 游戏时间结束后，会显示最终得分、正确率和最高连击
- 可以选择 "再玩一次" 重新开始游戏

## 🛠 技术实现

### 前端技术栈
- **HTML5**：页面结构和语义化标签
- **CSS3**：样式设计和动画效果
- **JavaScript**：游戏逻辑和交互功能
- **Web Audio API**：音效播放和控制

### 核心功能实现
- **键盘事件监听**：监听键盘按下和释放事件
- **游戏状态管理**：管理游戏进程、得分和统计数据
- **随机目标生成**：根据游戏模式和难度生成目标
- **外部词库加载**：通过 `fetch` 异步加载 JSON 词库文件，支持多年级切换
- **限时速打超时**：实现基于不同难度的超时机制，自动处理超时未输入的情况
- **暂停恢复计时**：暂停时保存剩余时间，恢复时从断点继续
- **实时反馈系统**：视觉和听觉反馈
- **计分算法**：基于速度、准确性和连击的计分系统
- **音频管理**：背景音乐和音效的播放控制
- **排行榜同步**：实现游戏设置与排行榜显示的实时同步

## 🔧 故障排除

### 游戏无法加载
- **检查文件路径**：确保所有文件在正确的位置
- **检查浏览器**：尝试使用 Chrome 浏览器
- **检查JavaScript**：确保浏览器启用了 JavaScript

### 没有声音
- **检查音频文件**：确保 `sounds` 目录中有正确的音频文件
- **检查浏览器设置**：确保浏览器允许音频自动播放
- **测试音效**：点击 "🎵 测试音效" 按钮测试音效

### 按键没有反应
- **检查键盘**：确保键盘工作正常
- **检查输入法**：确保使用的是英文输入法
- **检查游戏状态**：确保游戏已开始且未暂停

### 游戏卡顿
- **关闭其他标签页**：减少浏览器负担
- **清除浏览器缓存**：提高浏览器性能
- **使用本地服务器**：通过本地服务器运行游戏

## 📝 修改词库

### 词库结构
游戏使用外部 JSON 文件作为词库，位于 `words/` 目录下。每个文件包含三个难度级别，每个单词包含英文和中文释义：

- **easy**：简单单词（≤4 个字母）
- **medium**：中等难度单词（5-7 个字母）
- **hard**：困难单词（≥8 个字母）

### 如何修改词库

1. **打开文件**：使用文本编辑器打开 `words/` 目录下对应的年级 JSON 文件
2. **修改单词**：在对应的数组中添加或删除单词条目
3. **保存文件**：保存修改后的 JSON 文件
4. **刷新浏览器**：在浏览器中刷新游戏页面，新的词库将生效

### 词库示例

```json
{
    "easy": [
        { "en": "cat", "zh": "猫" },
        { "en": "dog", "zh": "狗" },
        { "en": "sun", "zh": "太阳" }
    ],
    "medium": [
        { "en": "apple", "zh": "苹果" },
        { "en": "happy", "zh": "快乐的" },
        { "en": "school", "zh": "学校" }
    ],
    "hard": [
        { "en": "computer", "zh": "计算机" },
        { "en": "keyboard", "zh": "键盘" },
        { "en": "student", "zh": "学生" }
    ]
}
```

### 添加新词库

1. 在 `words/` 目录下新建 JSON 文件，如 `grade7.json`
2. 在 `script.js` 的 `wordLibraries` 数组中添加新条目
3. 在 `index.html` 的 `.library-buttons` 中添加对应的按钮
4. 刷新浏览器即可使用

### 注意事项
- 词库数据来源：人教版小学英语 3-6 年级教材词汇
- 每个单词需包含 `en`（英文）和 `zh`（中文释义）两个字段
- 简单级别建议使用2-4个字母的单词
- 中等级别建议使用5-7个字母的单词
- 困难级别可以使用8个字母以上的单词
- 确保单词拼写正确，避免错误的单词影响学习效果
